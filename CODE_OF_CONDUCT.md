# Team Code of Conduct & Working Agreement

## 1. Our Pledge
We as members of Group 18 commit to making participation in our SET09803 DevOps project a harassment-free, collaborative and productive experience for everyone.

## 2. Team Expectations & Standards
* **Communication:** Use agreed channels (GitHub Issues, Discord/Teams) for project-related discussions.
* **Attendance:** Attend scheduled team meetings and standups. Provide early notice if unable to attend.
* **Pull Requests & Code Reviews:** All code must be submitted via Pull Requests to `develop`. Every PR requires at least one peer review before merging.
* **Task Ownership:** Team members are responsible for updating their assigned tasks on the Kanban/Sprint board (Zube.io).

## 3. Unacceptable Behavior
* Ghosting or failing to communicate for extended periods without prior notice.
* Overwriting or force-pushing code without team agreement.
* Dismissive or disrespectful behavior during discussions or code reviews.

## 4. Conflict Resolution Process
1. **Internal Resolution:** Address issues directly and constructively within the group.
2. **Escalation:** If a member repeatedly fails to complete assigned user stories or communicate, the issue will be logged via GitHub/Zube tasks and escalated to the module tutor/lecturer.
